# Неон-Раннер

Бесконечный раннер в одну кнопку. Одна HTML-страница, без зависимостей и без сборки.

**Играть:** https://valpan904-sys.github.io/neon-runner/

## Управление

| Действие | Телефон | ПК |
|---|---|---|
| Прыжок | тап по экрану | `Пробел` / `↑` / `Enter` / клик |

## Что внутри

- Canvas 2D, подстраивается под любой размер экрана и retina (devicePixelRatio до 2).
- Работает в портрете на телефоне и в лендскейпе на ПК, учитывает Safe Area (вырез камеры).
- Тач-жесты и зум отключены, чтобы игра не «уезжала» при тапах.
- Рекорд хранится локально в `localStorage` (ключ `neonRunnerBest`).
- Скорость растёт со временем (до x2.6), препятствия и монетки спавнятся с гарантированным зазором, который всегда перепрыгивается.
- Параллакс-звёзды, неоновая сетка-перспектива, частицы, тряска экрана при смерти, вибрация на телефоне.

## Локальный запуск

Просто открой `index.html` в браузере. Либо подними статику:

```bash
python -m http.server 8765
```

## Как менять сложность

В `<script>` внизу файла:

- `baseSpeed` — базовая скорость (сейчас `W * 0.55`).
- `ramp` в `update()` — ускорение со временем (`1 + elapsed/42`, потолок `2.6`).
- `spawnGap` — пауза между препятствиями (`speed * rand(0.80, 1.55)`).
- `coinScore += 10` — цена монетки.
